>How to add more libs, plugins & themes

1. Libraries (.athlib): drop into lib/ (or pass --lib /path/to/libs) and import with `use mylib;`.
2. Plugins (.athplugin): in Atherium Studio open Plugins -> + Import Plugin, or drop into .atherium-studio/plugins/.
3. Themes (.aththeme): in Atherium Studio open Themes -> + Import Theme (.aththeme)... .

Full language docs: https://github.com/Deadstillplays/Atherium/blob/main/LANGUAGE.md
