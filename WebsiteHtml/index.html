Introduction

Atherium is a lightweight coding language built bottom-up from a hand-designed binary ISA. Source files (.ath / .athlib) compile to readable assembly (.athasm) and compact bytecode (.athbin), executed by a sandboxed W^X x86-64 VM JIT or compiled straight into standalone zero-libc Linux ELF64 binaries — with zero external dependencies.

.athSource program
.athlibLibrary module
.athasmAssembly listing
.athbinBytecode image

Performance Notices

  • > Sandboxed W^X x86-64 VM JIT (default): Translates .athbin bytecode directly to native x86-64 code in-process with millisecond startup. Force the portable threaded interpreter with ATH_VM_NO_JIT=1 or reference stepping with ATH_VM_REF=1.
  • > Zero-Libc Standalone Native AOT: atherium native compiles .ath straight to a standalone Linux x86-64 ELF64 binary with an embedded freestanding runtime — no external linker, no libc, no runtime overhead.
  • > Configurable Flat Guest RAM: Defaults to 64M sandboxed memory; tune per program with --mem 64K up to --mem 6GiB. All compiler, JIT, and native optimizations are 100% general-purpose.
  • > Atherium Studio Startup Notice: The Linux .AppImage executes native zero-libc ELF64 directly (~1–2 ms run times). The Windows .exe unpacks its bundled stdlib & compiler sources once to %TEMP%/AtheriumStudio on first launch.

Installation & how to use

\ :)

>Main setup files

[ Clone / Download from GitHub -> ] 
$ git clone https://github.com/Deadstillplays/Atherium.git
$ cd Atherium && make                       # builds ./build/atherium (gcc or clang)
$ ./build/atherium run hello.ath            # run on W^X x86-64 VM JIT
$ ./build/atherium native hello.ath -o app  # compile standalone zero-libc ELF64
$ ./scripts/install_ath_icon.sh             # register .ath/.athlib/.athasm/.athbin icons

>Code editor (Atherium Studio)

Fast, bare-minimum native borderless desktop IDE written 100% in pure Atherium — featuring Luau-style predictive autocomplete, extensible .athplugin language plugins, interactive selectable terminal, custom .aththeme themes, native OS file dialogs, and 1-click import of the full Atherium compiler source into any project.
